# Email Classifier

## Configuration

Set your Gemini API key in a local `.env` file:

```env
GEMINI_API_KEY=your-gemini-api-key
```

The application loads `.env` at startup. `.env` files are ignored by Git; do not commit your real API key. See `.env.example` for the required variable name.

Install project dependencies before running:

```powershell
pip install -e .
```
